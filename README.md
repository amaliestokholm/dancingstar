# Simulation: Dancing star / seismic star

This is a small simulation, showcasing a star as a 3D oscillator and some of the possible modes of oscillation that can occur. 

This can also show a superposition of different modes so the user can have an idea of the complexity of the many movements but also that they can be described as a series of single mode oscillations. All movements are (of course) rather exaggerated for clarity.

This simulation will nicely tie in with a piece of text on asteroseismology that I am writing.

This is also a way for me to improve my js and css skills -- this is  not perfect, but it does exist.
